# v11：酷狗概念版式手机 UI + 交互修复

新增 `web/mr-phone/mr-phone-kugou.js`（独立模块，挂在 `mr-phone.js` 之后加载）。

## 新的手机 UI

### 底部导航（参考酷狗概念版）

`发现 | 旋转封面 | 我的`

- 非播放页：只显示这条导航（宿主原来的播放条 `#bottom-bar` 全部隐藏）
- 中间是**圆形旋转专辑封面**：播放时旋转、暂停时停住；点击进入播放页
- 订阅音频事件同步封面/旋转状态

### 播放页

- 顶部：`⌄` 收起按钮 + 居中歌名 + 歌手（酷狗式标题在顶部）
- 底部：进度条（可拖动 seek）+ 播放模式 / 上一首 / 播放暂停 / 下一首 / 队列 + 时间
- 背景沿用 App 的歌词/封面粒子舞台（移除 `empty-home-active`，让舞台可见）
- 播放页里隐藏搜索框、「…」、底部导航

### 我的（主页）

`我的` 页：账号卡片（未登录 → 登录按钮，调 App 原生登录）+ 我的歌单 / 本地歌曲 / 我的播客 / DIY 模式 入口。

## 交互修复

| 问题 | 处理 |
|---|---|
| 左半屏右滑误开歌单 | 包装 `window.setPeek('pl', true)`：非本 UI 主动打开时直接拦掉；本 UI 用 `__mrAllowPlOpen` 标记放行 |
| 滑动歌单列表就收起 | 之前把下滑关闭绑在整个面板上——现在只绑在**头部**（`playlist-panel-sticky`），列表滚动不再触发关闭 |
| 歌单没法关闭 | 头部 **✕** + 头部下滑 + 返回键 |
| 歌单底框没居中 | 面板改为左右各 8px 的整块（`left:8/right:8`），内容宽度一致 |
| 「…」压进搜索框、还在下层 | 搜索框右侧留 64px 给「…」；「…」`z-index:9500` 压到搜索框之上 |
| 返回键直接退 App | 播放页/我的 → 回首页；歌单/登录/搜索等浮层 → 关闭；首页不退出 |

## 真机验证

- 首页：搜索 + 「…」 + 底部三栏导航
- 点封面 → 播放页（顶部歌名/歌手、底部播放条、歌词粒子背景）
- 我的页：登录入口 + 歌单入口
- 我的歌单 → 面板打开、居中、✕ 可关
- 返回键：播放页 → 首页；面板 → 关闭；首页不退
