# v37：恢复「视觉控制台」按钮 + 登录页重新排版 + 修点击穿透

## 1. 视觉控制台按钮不见了

原因：`hideFab()` 之前为了不挡布局，把右下角的视觉控制台 FAB（`#fx-fab`）设成了 `display:none!important`。App 源码注释里其实写着「视觉控制台（右下角设置）在手机上要常驻可用」。

修复：不再隐藏，改成常驻在底栏上方右侧：

- `display:flex; visibility:visible`
- `right:12px`，`bottom = 底栏顶 - 12px`（每轮按底栏实际位置计算）
- 44×44、z-index 8550
- 点击可正常打开视觉控制台（`#fx-panel` 进入 peek 状态）

## 2. 登录页太挤、顶到边框

原来的登录页 CSS 是为“贴满全屏”写的（`padding:0`、`width:100%`、`max-width:none`）。

修复（CSS + 内联兜底双保险）：

- `#login-modal` 变成居中容器：左右 12px、顶部 `14px + 安全区`、底部 `20px + 安全区`
- `.dual-login-modal`：`max-width:420px`、圆角 20、`max-height:100%`、`overflow-y:auto`，不再顶边框
- 头部（退出登录 / ×）sticky 置顶，带圆角和分隔线
- 账号节点区左右各 8px 内边距，行宽 100%

## 3. 登录页能点到底下的搜索框

原因：手机壳里搜索框是 `z-index:9000`，而登录遮罩只有 `z-index:50`，搜索框浮在遮罩上面，点得到。

修复：

- 登录打开时隐藏搜索框/「…」按钮（`body:has(#login-modal.show)`）
- 登录遮罩 z-index 提到 **9600**，点击只会落在遮罩/弹窗上

## 验证（真机 v37）

- 首页/播放页右下角「视觉控制台」按钮常驻，点击能打开控制台
- 登录页左右有边距、圆角卡片、可上下滚动，不再顶边框、不再压状态栏
- 登录打开时搜索框隐藏，点击原搜索位置不会触发搜索
- 「退出登录」「×」、账号行「展示」开关、MR/官网/Cookie 均正常
