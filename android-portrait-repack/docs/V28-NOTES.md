# v28：播放页底栏点不动修复

## 原因

v27 为了让舞台可以单指拖动，在播放页加了一层全屏透明触摸层 `#mr-stage-overlay`。它的 `z-index:100`，而底栏 `#bottom-bar` 的 `z-index` 只有 32 —— 触摸层盖在底栏上面，把底栏按钮的点击全吃掉了。

（顶栏歌曲信息 8400、右上头像 9500 都在触摸层上面，所以只有底栏点不动。）

## 修复

触摸层 z-index 改为 **5**：

- 舞台画布 z-index 1 → 触摸层在画布之上，仍能接管拖动/缩放
- 底栏 z-index 32 → 在触摸层之上，按钮恢复可点
- 顶栏歌曲信息、右上头像不受影响

## 验证（真机）

- 播放页点播放键：`#play-btn` 收到 click（计数 +1），播放/暂停正常
- 播放页点击区域命中：`elementFromPoint(196,830)` 返回播放按钮里的 `#play-icon`
- 单指拖动仍可旋转：`orbit.userTheta` 0 → -0.64
- 双指缩放、顶栏、头像、返回键均正常
