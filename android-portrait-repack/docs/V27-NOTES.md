# v27：登录后「…」直接变账号头像 / 播放页控件与手势修复

## 1. 登录后右上角只显示一个按钮：账号头像

之前是「…」+ 头像两个按钮，理解错了。现在：

- 登录后，右上角那个 button 的内容直接换成**账号头像**（`#phone-chrome-more` 里的 dots SVG 替换为 `<img class="phone-chrome-avatar">`，头像来源是 App 原生 `#user-btn` 里的头像）
- 点它仍然**下滑弹出原来的菜单**：首页 / 登录 / DIY / 歌单
- 原来的 `#user-btn` 隐藏，不再单独出现
- 未登录时仍显示「…」三个点

## 2. 播放页底栏左右图标回来了

底栏 5 个：随机/循环模式 · 上一首 · 播放 · 下一首 · 列表（队列）。

之前沉浸式模式把 `#play-mode-btn`、`#mini-queue-btn` 显示了又隐藏，现在播放页强制 `display:flex`。

## 3. 播放页点账号没反应、返回才看到登录页

原因：之前右上角放的是 App 原生 `#user-btn`，点它是原生账号逻辑（打开登录面板），在播放页被舞台挡住，回首页才看到登录页。

现在头像按钮走我们自己的菜单（同一套「首页/登录/DIY/歌单」），播放页点它直接弹菜单，不会再出现"没反应"。

## 4. 播放页手势：滑动旋转 + 双指缩放，点按不再强制复位

- 播放页加了一层透明触摸层 `#mr-stage-overlay`（在舞台之上、顶栏/底栏之下），单指拖动直接改 `orbit.userTheta / userPhi` → **手指滑动可以旋转视角**
- 双指仍然走原来的 pinch → `orbit.userRadius`，缩放保持不反弹
- 单指点击/双击不再传给宿主的相机逻辑（之前点左半边会强制换角度和远近）
- 之前的问题是宿主每帧把 `userTheta` 往 baseline 上拉，直接改 `orbit.theta` 会被覆盖，所以改成改 `userTheta`，旋转就能保持

## 真机验证（v27）

- 首页：右上角只有账号头像，点开菜单=首页/登录/DIY/歌单
- 播放页：顶部歌曲信息 + 头像；底栏 随机/上一首/播放/下一首/列表；手指拖动可旋转（theta 0 → -0.64），点一下视角不变
- 返回键、状态栏、提示条均正常
