# v30：底栏 7 键（循环/列表贴边 + 收藏/自动混音进栏），播放页附加行 + 进度时间

按酷狗概念版参考，把平板底栏的按键重新分配到手机底栏。

## 1. 手机底栏 7 个键

顺序（左右贴边布局）：

```
[循环模式] [收藏] [上一首] [播放] [下一首] [自动混音] [列表]
```

- 循环模式在最左，列表在最右（`justify-content:space-between`）
- 原来被手机壳隐藏的「收藏 `#heart-btn`」和「自动混音 `#cuefield-automix-btn`」移进底栏并显示
- 节点从 `actions` 集群搬到 `transport` 集群，事件和图标都是 App 原生的
- 每轮布局函数 `layoutPhoneBar()` 保证顺序（宿主重渲染后自动纠正）

## 2. 播放页：底栏上方一排四个

把原位移动端隐藏的四个键搬到播放条上方右侧：

`词（歌词） · 音量 · 控制条自动隐藏 · 全沉浸`

容器 `#mr-player-extras` 固定在底栏上方（bottom 每次按底栏实际高度计算），只在播放页显示；退出播放页会自动搬回原位。

## 3. 进度条两侧显示已播放/总时长

- 进度条被包进 `#mr-progress-row`：`[0:11] [======进度======] [4:30]`
- 时间由 `audio.currentTime / audio.duration` 每 900ms 同步（也跟随 timeupdate）
- 进度条节点是原来的 `#progress-bar`，拖动/点击 seek 逻辑不变

## 验证（真机 v30）

- 首页底栏 7 键顺序正确：play-mode / heart / prev / play / next / cuefield / mini-queue
- 播放页：附加行 4 个键（词/音量/控制条/沉浸）全部可见；底栏 7 键；进度条两侧时间 0:00 / 0:00（暂停时）与 0:11 / 4:30（播放时）
- 底栏按钮可点（此前 v28 已修遮罩层）
